# Description

The main objective of this repository is to share the artifacts produced during the development of the systematic perspective on the literature, regarding a comprehensive understanding of technical explorations of observability for adaptive NFV contexts.

# Artefacts
The artifacts shared here are organized as follows:

* The `Sources` directory contains the research repositories of the identified works, as well as the metadata (in CSV and BibTeX formats) resulting from the search string used;
* The Python script `merge-references.py`, when executed, recursively removes duplicate entries from the research repositories, identifying them based on their titles in a case-insensitive manner;
* The `requirements.txt` file that list the Python libraries required to run the script;
* The `merged-output.csv` file, generated as output by the Python script, containing the list of identified works with duplicates removed;
* The `summary.log` file, also generated by the Python script, shows the total, duplicated, and unique works, in addition to listing the duplicated works and their source files.
* The `merged-output-without-acm-proceedings-books.csv` file that contais the works after removing full proceedings (146) and books (26) from ACM;
* The `Selection Process` directory, which contains the separate files and their respective data extracted during each phase of the primary study selection process: screening, eligibility, and inclusion.

# Executing Python Script
## Basic Information
The artifacts produced and used originate from a computational environment with the following configurations:
* Intel Core i7-1355U;
* 16GB of RAM (DDR4, 3,200 MT/s);
* Ubuntu 24.04.5 LTS.

## Dependencies
To reproduce the results of removing duplicated works, Python 3.12 must be installed, and the modules described in the `requirements.txt` file must be properly configured.

## Python and Modules
First, it necessary to verify that the Python library is installed and is the correct version by using the following command:
```
python3 --version
```

The output should be something similar to the following message:
```
Python 3.12
```

If the output is not the same as the previous one, install using the command:

```
sudo apt install python3.12
```

After setting up Python, it is necessary to install the external modules listed in the *requirements.txt* file. To do this, run the following command:
```
xargs -a requirements.txt sudo apt install -y
```

## Script Execution
To run the script, simply execute the following command:
```
python3 merge-references.py
```
or
```
python3 merge-references.py --source-dir Sources
```

The expected output contains two files: `merged-output.csv` and `summary.log`.
